# LiveCue Fluent Blue icon

Generated with the built-in image generation tool, using the selected Fluent Blue concept board as a style reference. PNG is the original generated asset; ICO is a multi-resolution format conversion.

## Prompt

Use case: logo-brand. Create a production Windows desktop app icon for LiveCue. Reference image is the selected Fluent Blue concept board; use only its blue flowing ribbon icon as design reference, not the interface. Single large centered icon, front facing: dimensional cobalt and azure folded ribbon forming one soft sine wave, on an icy pale-blue rounded-square tile. Crisp silhouette readable at 24px. Square 1024x1024 canvas, tile fills 94% of canvas. Genuinely transparent background outside rounded tile, preserve alpha. No text, no labels, no shortcut arrow, no mockup, no surrounding scene, no extra icons. Polished Windows Fluent material and restrained soft shading.
